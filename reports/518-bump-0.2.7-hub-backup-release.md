# Report 518 — Version bump 0.2.7 for the Hub backup/restore release

## 1. Identification
- **Report number:** 518
- **Task ID:** release prep (HUB-BACKUP-RESTORE, PR #133)
- **Predecessor task:** report 517 (Task 6)

## 2. Objective
Give the backup/restore feature its own release number.

## 3. Modified Files
- `backend/pom.xml` (`0.2.6.1.1` → `0.2.7`)
- `PROGRESS.md`, `reports/518-bump-0.2.7-hub-backup-release.md`

## 4. What Changed?
`pom.xml` version bumped; `ember-hub/build-installer.ps1` reads it, so the installer becomes `EmberHubSetup-0.2.7.exe` and the jar/jpackage version `0.2.7`.

## 5. Why It Changed?
Versioning so far: feature releases bump the third number (0.2.4 → 0.2.5 → 0.2.6), hotfixes append a fourth (0.2.5.1, 0.2.6.1, 0.2.6.1.1). Backup/restore is a feature, so `0.2.7`. `HubVersion.isNewer` compares numerically per component, so `0.2.7` is newer than `0.2.6.1.1`; a backup made by 0.2.7 will (by design) refuse to restore on an older Hub. Not built into a release yet: this is the test build for `VERIFY.md` 14-19.
