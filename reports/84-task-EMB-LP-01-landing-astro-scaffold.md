# Report 84 — EMB-LP-01

## 1. Identification
- **Report:** 84
- **Task ID:** EMB-LP-01
- **Predecessor Task:** EMB-PC-14 (report 83)

## 2. Objective
Scaffold a standalone `ember/landing/` Astro project — own `package.json`/lockfile, not a `frontend` workspace member — with Tailwind CSS 4 and `@astrojs/react` wired in, dev server on port 5174.

## 3. Modified Files
- `landing/` (new, via `pnpm create astro@latest`): `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`, `tsconfig.json`, `astro.config.mjs`, `.gitignore`, `.vscode/`, `AGENTS.md`, `CLAUDE.md` (symlink → `AGENTS.md`, generated by `create-astro`), `README.md`, `public/favicon.ico`, `public/favicon.svg`, `src/pages/index.astro`
- `landing/astro.config.mjs` — added `@astrojs/react`, `@tailwindcss/vite`, `server.port: 5174`
- `landing/src/styles/global.css` (new) — `@import "tailwindcss";`
- `landing/src/pages/index.astro` — imports the new stylesheet, one Tailwind utility class added to the placeholder heading as a smoke test

## 4. What Changed?
Ran `pnpm create astro@latest . --template minimal --typescript strict --install --no-git --yes` inside the pre-existing empty `landing/` directory (Astro 7.2.2). Ran `pnpm astro add react --yes`, which installed `@astrojs/react` + `react`/`react-dom` and wired the integration into `astro.config.mjs` and `tsconfig.json` (`jsx: react-jsx`). Installed `tailwindcss` + `@tailwindcss/vite` directly (Tailwind 4's Vite-plugin path, not the old `@astrojs/tailwind` integration) and registered `tailwindcss()` in `vite.plugins`. Added `server: { port: 5174 }` to `astro.config.mjs`. Created `src/styles/global.css` with the Tailwind 4 `@import` entrypoint and imported it from `index.astro`, adding one utility class to prove the pipeline compiles. Verified with `astro build` (via `pnpm run build`) — 1 page built, and the emitted `dist/_astro/*.css` contains compiled Tailwind output. Removed the resulting `dist/` (already gitignored) after verification.

## 5. Why It Changed?
Matches the approved EMB-LP-01 plan and the landing-page spec (`docs/superpowers/specs/2026-08-13-ember-landing-page-design.md`): a fully independent Astro package (own lockfile/`pnpm-workspace.yaml`, zero coupling to `frontend`'s workspace) so the marketing site can be deployed/built separately, with Tailwind 4 kept at the same major version as `frontend` and `@astrojs/react` pre-wired for the interactive islands due in EMB-LP-05/11/12. Port 5174 avoids colliding with `frontend`'s dev server (5173).
